# Week 8 - Ring-LWE and Module-LWE

## Objectives
- Understand polynomial rings used in Ring-LWE.
- Practice polynomial multiplication modulo x^n + 1.
- Build small Ring-LWE and Module-LWE examples.
- Compare the structure of both problems.

## Tools
Python, NumPy, VS Code

## Files
- polynomial_ring.py - basic ring arithmetic
- ring_lwe_basics.py - small Ring-LWE sample
- ring_lwe_sample.py - Ring-LWE equation
- module_lwe_basics.py - small Module-LWE example
- ring_vs_module_lwe.py - structural comparison

## Conclusion
Week 8 connects the lattice work from Week 7 with structured lattice problems used in post-quantum cryptography. The examples are intentionally small so the calculations can be inspected directly.
