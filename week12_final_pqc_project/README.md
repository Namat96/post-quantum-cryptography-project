# Week 12 - Final Post-Quantum Cryptography Project

This is the last week of my post-quantum cryptography project.

In the previous weeks, I studied the basic mathematics, LWE, lattice reduction, Ring-LWE, Module-LWE, ML-KEM (Kyber), and ML-DSA (Dilithium). In this week I put the main points together and reviewed what I learned.

## What I covered

- LWE and lattice cryptography
- Ring-LWE and Module-LWE
- ML-KEM (Kyber)
- ML-DSA (Dilithium)
- Basic performance observations
- Final research conclusion

## Files in this folder

- `final_pqc_summary.py` - short summary of the whole project
- `lwe_summary.py` - review of the LWE work
- `kyber_summary.py` - review of the Kyber work
- `mldsa_summary.py` - review of the ML-DSA work
- `performance_summary.py` - simple performance observations
- `research_conclusion.md` - final research report

The Python programs are small learning examples. They are not complete implementations of the real cryptographic standards.
