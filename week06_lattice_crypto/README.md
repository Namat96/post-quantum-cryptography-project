# Week 6 - Lattice Cryptography Fundamentals

## Objectives

By the end of Week 6, I will be able to:

1. Understand the basic mathematical structure of lattices.
2. Represent lattices using basis vectors and matrices.
3. Explain SVP and CVP.
4. Understand the relationship between LWE and lattice-based cryptography.
5. Perform simple computational experiments with lattices.

## Topics Covered

- Lattice basics
- Lattice basis vectors
- Lattice matrix representation
- Shortest Vector Problem (SVP)
- Closest Vector Problem (CVP)
- LWE and lattice connection

## Tools

- Python
- NumPy
- VS Code

## Practical Experiments

1. `lattice_basics.py` - Generates lattice points using basis vectors.
2. `lattice_matrix.py` - Represents a lattice using a matrix.
3. `svp_basics.py` - Demonstrates the Shortest Vector Problem.
4. `cvp_basics.py` - Demonstrates the Closest Vector Problem.
5. `lwe_lattice_connection.py` - Demonstrates the basic connection between LWE and lattices.

## Learning Outcome

This week builds the mathematical foundation needed to understand
lattice-based cryptography and post-quantum cryptographic schemes.
